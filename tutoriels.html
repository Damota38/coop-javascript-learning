🎮 Jeux & Exercices JS

Teste et renforce tes compétences sur var, let, const et les fonctions !

1️⃣ var vs let

Objectif : Comprendre la portée (scope) des variables.

Énoncé détaillé :
Dans la fonction test(), on déclare x avec var et y avec let dans un bloc. Que va afficher la console à chaque console.log ? Indique les deux résultats, séparés par une virgule. 


                            // Code :
                            function test() {
                              if (true) {
                                var x = 1;
                                let y = 2;
                              }
                              console.log(x);
                              console.log(y);
                            }
test();
1 → 1 (x visible hors du bloc)
2 → ReferenceError (y non défini hors du bloc)
2️⃣ const

Objectif : Voir qu’une constante ne peut pas être réaffectée.

Énoncé détaillé :
On définit const MY_POTION = 'vie'. Complète la ligne suivante pour qu’elle lance une TypeError lors de l’exécution. 


                            //…
// À compléter ici :
MY_POTION = 'mana';
→ TypeError : assignment to constant variable.
3️⃣ Fonctions

Objectif : Associer chaque style de fonction à sa caractéristique.

Énoncé détaillé :
Trois syntaxes de déclaration en JS :
– function foo(){…} (classic, hoisted)
– const foo = function(){…} (expression)
– const foo = ()=>{…} (arrow)
Choisis le bon type pour chaque description.

- Classic → classic
- Expression → expression
- Arrow → arrow
4️⃣ Redeclaration var vs let

Objectif : Comprendre la redéclaration de variables.

Énoncé détaillé :
Prédisez les deux logs : que renvoie console.log pour a et b ? Indiquez les deux résultats par une virgule. 


                                // Code :
                                var a = 1;
                                var a = 2;
                                console.log(a);
                                
                                let b = 1;
                                let b = 2;
console.log(b);
1 → 2 (var redéclaré OK)
2 → SyntaxError (let interdite)
5️⃣ Mutation & const

Objectif : Différence réassignation vs mutation.

Énoncé détaillé :
Que renvoient ces deux logs ? Indiquez les résultats par une virgule. 


                                // Code :
const potion = { level: 1 };
potion.level = 5;
console.log(potion.level);
potion = { level: 10 };
console.log(potion.level);
1 → 5 (mutation OK)
2 → TypeError (réassignation interdite)
